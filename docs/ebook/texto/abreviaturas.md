# Lista de abreviaturas e siglas

| Sigla | Significado |
|---|---|
| AABB | *Axis-Aligned Bounding Box* (caixa envolvente alinhada aos eixos) |
| ABNT | Associação Brasileira de Normas Técnicas |
| CG | Computação Gráfica |
| CI | Integração contínua (*Continuous Integration*) |
| dBFS | Decibéis em relação à escala cheia (*decibels relative to full scale*) |
| FPS | Quadros por segundo (*frames per second*) |
| GIF | *Graphics Interchange Format* |
| HUD | *Heads-Up Display* (faixa de informações do jogo) |
| JPEG | *Joint Photographic Experts Group* (formato de imagem) |
| MVC | *Model-View-Controller* (modelo, visão e controlador) |
| PNG | *Portable Network Graphics* |
| PR | *Pull request* |
| RGB | *Red, Green, Blue* (vermelho, verde e azul) |
| RGBA | RGB com canal alfa |
| SDL | *Simple DirectMedia Layer* |
| UNIP | Universidade Paulista |
| WAV | *Waveform Audio File Format* |
