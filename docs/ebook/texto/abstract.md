# Abstract

This educational ebook presents the fundamental concepts of two-dimensional Computer Graphics through a real project: the Snake Game (Jogo da Cobrinha), developed in Python with the pygame-ce library for the Computer Graphics course at Universidade Paulista (UNIP). After an introduction to the field and its history, the text describes the evolution of the project, from the first version, built by a group of students in 2025, to release 3.1.0, and presents the code architecture, which separates the game rules, written without any graphics dependency, from the interface that draws them. Each chapter then explains one concept based on reference textbooks, classic papers and official documentation, and shows where and how it was applied in the game, with real code excerpts identified by file and line. The topics are raster graphics and double buffering, coordinate systems and the mapping from the logical grid to pixels, the game loop with a fixed time step, the 2D drawing pipeline and the painter's algorithm, procedural pixel art generated from distance functions, geometric transformations and nearest-neighbor scaling, the RGB model and median cut color quantization, alpha compositing according to Porter and Duff, animation, grid-based collision detection, clipping and edge wrapping, as well as the user interface and synthesized sound. A case study analyzes the interpolated movement of the snake, which was implemented and later reverted as a design decision. All figures, including flowcharts and screenshots, are generated by scripts kept in the repository. The ebook includes a glossary and hands-on exercises.

**Keywords:** computer graphics; digital games; pixel art; Python; pygame.
